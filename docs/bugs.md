# Баги

Формат: `B<n>` · где найден · статус. Найденные на боевом тесте — с пометкой среды.

## Открытые

### B1 · быстрый подбор, экран прогресса · open
Среда: Manjaro GNOME, ноут, v0.1.0 (e36b229).
Список хостов в UI: Сайт, Приложение/API, Превью, Видео — но подсветка прогресса начинается со
второго пункта, а не с «Сайт».
Вероятная причина: helper проверяет хосты в порядке `youtubei.googleapis.com` → `www.youtube.com`
→ видео → `i.ytimg.com` (сначала самый «трудный» youtubei), а UI рисует фиксированный порядок
site/api/thumbs/video → первым активен `api`. Решение: либо UI рисует в порядке проверки из
`hosts[]`, либо helper проверяет в порядке UI.

### B2 · расширенный режим, ручной выбор способа · open (UX)
Среда: та же. После выбора способа из списка нет явного подтверждения, что он применён и
сервис перезапущен — пользователь не был уверен и вручную выключил/включил. По логам применение
сработало само (apply → перезапуск за ~1 с). Нужно: короткое подтверждение «Способ применён» /
индикатор на время перезапуска.

### B3 · главный экран, переключатель Вкл/Выкл · open (UX)
Среда: та же. Пока идёт включение/выключение (pkexec + systemd, несколько секунд), переключатель
заблокирован, но больше ничего не меняется — приложение выглядит зависшим. Нужен индикатор
процесса на месте блока текущего статуса: лоадер/прогресс и текст «Включаем…» / «Выключаем…».
Связано с B2 (тот же паттерн: действие без видимой обратной связи).
