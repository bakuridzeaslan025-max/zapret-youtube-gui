# Дизайн-спека (из макета Claude design)

Источник: `docs/YouTube без блокировок - макеты.html` — бандл Claude design (манифест ресурсов
в base64/gzip + шаблон). Внутри: статичная HTML-вёрстка на инлайн-стилях, дизайн-система
«Nocturne», шрифт Inter, иконки Phosphor (regular/fill/bold). React в бандле только для
рантайма холста дизайна, самим экранам он не нужен → renderer на ванильном JS.

Эталонные скриншоты макета: `docs/screenshots/mockup/<id>-<theme>.png`,
скриншоты приложения (mock-режим): `docs/screenshots/<id>-<name>-<theme>.png`.

## Экраны и состояния

Окно 440×640, своя шапка 44px (заголовок, [шестерёнка], свернуть, закрыть; на вложенных
экранах — «назад» + заголовок раздела). Каждый экран — «центр» (иконка-бейдж, заголовок,
пояснение) + «подвал» с 1–2 кнопками на всю ширину.

Добавлено сверх макета: `error` — общий экран ошибки (`BUSY`/`HELPER_FAILED`/прочие) в стиле
1d с кодом ошибки и «Повторить»/«Закрыть» (скриншот `x-error-*`); `close-warn` — предупреждение
при закрытии без трея во время подбора (скриншот `x-close-warn-*`).

### Закрытие окна и трей (docs/ipc-api.md, «Закрытие окна»)

- Трей определяется в main: владелец `org.kde.StatusNotifierWatcher` на session bus
  (`gdbus`, запасной — `dbus-send`, через `execFile` без shell). Не Linux или нет утилит —
  считаем, что трей есть. `YTU_TRAY=0|1` — принудительно (тесты).
- Трей есть: закрытие прячет окно; в первый раз — уведомление «Свёрнуто в трей» (флаг в userData).
- Трея нет: закрытие завершает GUI. Если идёт подбор — экран `close-warn` («Подбор продолжится,
  результат увидите при следующем запуске», «Закрыть» / «Не закрывать»). На экране глубокого
  подбора «Свернуть в трей» заменяется на «Свернуть», пункт про трей в 4a — на текст о закрытии.
- Запуск при идущем подборе сразу открывает экран подбора (`quick`/`deep` по последнему
  `selectProgress`, который main повторяет при загрузке окна).

## Расхождения макета с `docs/ipc-api.md`

Нет поддержки в API (что сделано сейчас):

| Что в макете | Проблема | Сейчас | Предложение |
|---|---|---|---|
| 1c: шаги установки | прогресс — необязательное событие `installProgress {step: string, done, total}` | 4 шага макета заполняются пропорционально `done/total`; без событий — неопределённый бар, спиннер на 1-м шаге | — (в контракте есть) |
| 1e: какой пакет ставить | `requirements.missing` — имена компонентов, дистрибутив неизвестен | команда для apt по карте компонент→пакет, «для Fedora…» ведёт на справку | `requirements.hints: {distro, command}` из helper |
| 1f: «Добавить исключение» | метода нет | повторный `install()` | `install({firewallException: true})` или отдельный метод |
| 3a: галочки хостов по текущему способу | `selectProgress` без по-хостовых результатов | необязательное поле `hosts: [{key, ok: bool\|null}]`; без него — все строки «ожидает» | добавить `hosts` в `selectProgress` (blockcheck2 может не отдавать по-хостово — тогда убрать из макета) |
| 4b: «идёт 48 мин» | нет времени старта | необязательное `startedAt` в `selectProgress`, иначе — локальный таймер renderer'а | добавить `startedAt` |
| 5d / 3a при открытии окна посреди подбора | `State` не содержит прогресс | main кэширует последний `selectProgress` и повторяет его при загрузке окна (`ipc.js`) | `State.selection: {mode, done, total, …} \| null` |
| 4c: «Напомнить завтра» | нет планировщика | таймер в renderer + HTML5-уведомление (живёт, пока запущено приложение) | метод `remindLater(hours)` в main/сервисе |
| 4c: «Отправить отчёт» | нет отправки, есть только `getReport()` | копируем отчёт в буфер + тост | эндпойнт/ссылка для отправки (решить) |
| 6b: «Текущие параметры» (nfqws2 …) | `listStrategies()` без аргументов | показываем необязательное поле `args`, если есть | добавить `args` в `listStrategies` |
| 6b: «ALT 3 — подобран автоматически» | неизвестно, авто или вручную | пишем «— текущий» (+ «приближённый» для `exact=false`) | `strategy.origin: 'auto'\|'manual'` |
| Шапка: свернуть/закрыть/«Свернуть в трей» | не система, а окно | отдельный `window.appWindow` (`minimize/close/hideToTray`), `window.api` не тронут | — |
| 7b: уведомление | — | `Notification` в main по `selectDone`, если окно не в фокусе | — |
| «Справка»/«Полная справка на сайте» | URL не определён | временный `HELP_URL` в `renderer/app.js`, main открывает только https на хостах из allowlist | определить сайт справки |

Есть в API, нет в макете: коды `AUTH_FAILED`, `NOT_INSTALLED`, `BUSY`, `HELPER_FAILED`
(→ `err-auth` и общий `error`); `listStrategies().source/exact` (показываем только `exact`);
`networkChanged` (UI строит баннер из `State`: сеть есть, стратегии нет); `requirements.missing`
до установки (макет показывает только одну недостающую вещь — модуль ядра);
`Network.kind` `ethernet`/`other` (иконки `network`/`globe-simple` — выбраны мной).

## Контракт сервиса для `app/main/services/{mock,real}.js`

Модуль экспортирует `create({app})` (или сам объект), возвращающий объект с async-методами из
таблицы `window.api` и `on(event, cb)` (EventEmitter). Ошибки — `throw` объекта/Error с
`code` из списка кодов и `message`; прочее ipc.js превращает в `HELPER_FAILED`. События:
`state`, `selectProgress`, `selectDone`, `networkChanged`, опционально `installProgress`.
Выбор: `YTU_SERVICE=mock|real`, по умолчанию `real`, если есть `real.js`, иначе `mock`.
Сценарии мока: `YTU_MOCK_SCENARIO` = `fresh` (по умолчанию), `auth-cancel`, `missing`,
`firewall`, `unblocked`, `path`, `on`, `off`, `broken`, `selecting-on-start`, `deep-running`, `deep`,
`deep-fail`, `new-network`, `helper-fail`; скорость — `YTU_MOCK_SPEED` (множитель).

Тихий режим для автотестов: `YTU_HEADLESS=1` — offscreen-окно (DPR 2, `YTU_HEADLESS_DPR`),
никогда не показывается, без трея, уведомлений и иконки в Dock, отдельный временный userData
(параллельные прогоны не упираются в single-instance lock). `npm run screenshots` — в нём по умолчанию.

## Отличия реализации от макета

- Окно без скругления и тени (frameless прямоугольник): прозрачные окна на Linux зависят от
  композитора — не рискуем.
- Выпадающий список способа — нативный `<select>` в стиле `.input`.
- 6b: в макете раскрытый блок заменяет содержимое; у нас он раскрывается под карточкой в
  прокручиваемых настройках (журнал ограничен по высоте, автопрокрутка вниз).
- Иконки трея — PNG под тёмную и светлую панель одновременно (средние тона), без
  «обводки цветом панели» у точки ошибки (у прозрачной иконки нет фона панели).
