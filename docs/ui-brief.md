# Бриф для дизайна: десктоп-приложение «YouTube без блокировок» для Linux

## Что это

Небольшое десктоп-приложение для Linux (распространяется одним файлом AppImage), которое
возвращает работу YouTube у пользователей, чей провайдер замедляет или блокирует его через DPI.
Внутри — утилита zapret, но пользователь о ней знать не обязан. Главная фича — **автоподбор**:
приложение само находит способ обхода, который работает именно у этого провайдера.

## Для кого

Обычные пользователи Linux-десктопа (Ubuntu, Mint, Fedora и т.п.), не сетевые инженеры. Они
знают только «YouTube не грузит / видео не играет». Терминологию (DPI, стратегия, SNI, nfqws)
в основном интерфейсе не показываем; она доступна только в «Подробнее» / расширенном режиме.

## Платформа и стиль

- Десктоп-окно, компактное (ориентир ~440×640), не на весь экран. Плюс иконка в системном трее.
- Светлая и тёмная тема (следовать системной).
- Нейтральный, спокойный, «системный» вид — должен органично смотреться рядом с GNOME и KDE.
  Без агрессивного «хакерского» стиля.
- Язык интерфейса — русский (заложить возможность локализации).
- Один главный статус, крупно и понятно; одно главное действие на экране.

## Ключевые ограничения, влияющие на UX

- Для установки и включения нужен пароль администратора (системное окно запроса пароля Linux).
  Спрашиваем один раз при установке; дальше включение/выключение без пароля.
- Во время подбора защита выключена — YouTube в этот момент может не работать. Нужно предупредить.
- Быстрый подбор — ~1–3 минуты. Глубокий подбор — от десятков минут до нескольких часов,
  нужен прогресс, возможность отменить и свернуть в трей.
- Способ обхода зависит от сети: дома на Wi-Fi один, на мобильном интернете другой.

## Экраны и состояния

### 1. Первый запуск (онбординг)
- Короткое объяснение в 1–2 фразы: что делает приложение.
- Кнопка «Установить» → системный запрос пароля → прогресс установки (несколько шагов).
- Ошибки установки: пароль не введён/отменено; в системе не хватает компонента ядра;
  конфликт с включённым файрволом (firewalld/ufw) — понятный текст и что сделать.

### 2. Проверка сети (перед подбором)
Приложение проверяет, есть ли вообще блокировка. Три исхода, каждый — свой понятный экран:
- «YouTube у вас работает без блокировок» — помощь не нужна (можно всё равно включить).
- «Провайдер блокирует YouTube» → предлагаем подобрать способ обхода.
- «Проблема не в блокировке» (нет интернета / недоступен сервер) — подбор не поможет, подсказки.

### 3. Быстрый подбор
- Прогресс «Проверяем способ 5 из 18», название текущего способа — второстепенно.
- Список проверяемых сервисов YouTube с галочками: сайт, приложение/API, превью, видео.
  Способ засчитывается, только если прошли все четыре.
- Предупреждение: «Во время проверки YouTube может не работать».
- Кнопка «Отменить».
- Нашли → экран успеха. Не нашли → предложение глубокого подбора.

### 4. Глубокий подбор
- Перед стартом — предупреждение о длительности (до нескольких часов) и подтверждение.
- Прогресс с примерной оценкой оставшегося времени, число проверенных вариантов.
- «Свернуть в трей» и «Отменить». Уведомление, когда закончилось.
- Не нашли ничего → честный экран: «Не удалось подобрать способ» + варианты (попробовать
  позже, отправить отчёт, ссылка на помощь).

### 5. Главный экран (обычное использование)
- Крупный статус: **Работает** / **Выключено** / **Не работает — нужна перепроверка** / **Идёт подбор**.
- Главный переключатель Вкл/Выкл.
- Строка про текущую сеть: «Домашний Wi-Fi — способ подобран 12 сентября».
- Кнопки: «Проверить сейчас», «Подобрать заново».
- Если сеть сменилась и для неё способ ещё не подобран — заметный баннер «Новая сеть — подобрать?».

### 6. Настройки
- Запускать при старте системы.
- Отключать QUIC для YouTube (включено по умолчанию; с пояснением «нужно для работы обхода»).
- Запоминать способ для каждой сети.
- Расширенный режим (свёрнуто): текущие параметры, выбор способа вручную из списка, журнал
  событий, «Скопировать отчёт для поддержки».
- «Удалить приложение из системы» (снова пароль администратора) — в самом низу, опасное действие.

### 7. Трей
Иконка отражает статус (работает / выключено / ошибка / подбор с прогрессом). Меню: вкл/выкл,
открыть окно, проверить, выход.

### 8. Известные ограничения (справка)
Экран или раздел: например, старые устройства/браузеры без современного шифрования (TLS 1.3) не
поддерживаются; обход работает только на этом компьютере, не на телевизоре/телефоне.

## Что нужно от дизайна

Макеты всех экранов выше в светлой и тёмной теме, состояния главного экрана, иконка приложения и
иконки трея для каждого статуса, тексты-заглушки на русском.
